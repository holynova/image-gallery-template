# Image Gallery Template

> 用图片、主题和一句话需求，生成可上线的图片画廊。

![截图](./public/readme-preview.png)

原图放入 `incoming/`，内容写入 `content/`。运行 `npm i`、`ingest`、`validate`、`build`。

Astro + Sharp 生成 AVIF/WebP/JPEG 媒体，支持懒加载、筛选、灯箱、键盘/触摸导航和 Umami 统计。
